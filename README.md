# Agnes 桌宠

Agnes Harness Web 工作台的悬浮桌宠。启用后显示在工作台右下方。自 0.1.2 起，桌宠会在输入区上方自动缩放，让出模型选择等控件的点击空间。会话空闲时可以点一下桌宠，让它随机表演一个动作。

## 安装

1. 在已初始化的 Agnes Harness 环境运行 `agh home info` 查看当前运行目录。源码版可运行 `node .\agnes.mjs home info`。
2. 将归档中的 `package` 目录解压，命名为 `agnes-desktop-pet`，放进该运行目录的 `plugins` 文件夹。源码版可直接复制本目录到同一位置。
3. 在 Web 的插件管理页重新扫描本地插件，或在下次启动 Agnes Harness 时自动发现。启用后刷新 Web 工作台。停用可在同一插件管理页完成。

在 Windows 上，先让 Agnes Harness 自行初始化运行目录，再放置插件。

## 动作与触发

| 动作 | 触发 |
| --- | --- |
| 托腮思考 | 当前回合进入模型推理、尚未输出回答正文 |
| 转圈跳舞 | 当前会话收到新的成功结束结果 |
| 等待时发散 | 回合停在待确认、待回答或挂起状态 |
| 操作笔记本电脑 | 执行工具、其他工作阶段或正在输出回答正文 |
| 垂头丧气 | 当前会话收到新的失败结果 |
| 旋转飘落、跑动、倒下躺平 | 确认会话空闲后，每隔约 18–44 秒随机触发一次。点击空闲桌宠也可触发 |

状态由当前会话的有界 UI 投影驱动。历史结果不重播，取消结束回到待机。新运行状态接管随机动作。页面隐藏时暂停绘制，系统启用减少动态效果时显示各状态的代表姿势。图像来自用户提供的造型与标志，使用 ImageGen 制作帧并导出为带透明通道的 WebP 图集。插件只声明 UI 能力。

## 插件市场

在 Agnes Harness 的「插件 → 市场 → 社区」搜索 Agnes 桌宠。开发期间已本地安装示例版的用户，可继续使用示例版的本地更新，或停用示例版后安装市场版。
